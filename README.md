# 履歷 Lvli

保險業務專用的客戶資料夾，單一 `index.html`，不需伺服器。

- 用瀏覽器直接開啟 `index.html`（或部署到 GitHub Pages），手機可「加入主畫面」。
- 資料存在該瀏覽器的 LocalStorage；請定期用右上角「備份 / 還原」匯出 `.json` 存到雲端硬碟。
- 保險年齡：足歲，距上次生日超過六個月加一歲。
- 名單頁（列名單）：快速輸入或批次貼上，A/B/C 分級、聯繫狀態，一鍵轉為客戶卷宗。
- 關係連結：客戶之間互相綁定（配偶、父母↔子女、轉介紹人↔轉介紹對象），自動統計每位貴人介紹與成交數。
- 保障缺口：填入「現有 / 目標」額度產生進度條；「簡報檢視」頁含雷達圖，可直接給客戶看或列印成 PDF。
- 線上版：`python3 scripts/build_artifact.py` 產生 claude.ai Artifact 版本（資料私人同步到自己的帳號、備份透過下載確認）。
- 快捷鍵：`/` 聚焦搜尋。
